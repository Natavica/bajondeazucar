# VERDE & CACAO — Landing de pastelería vegana

Prototipo frontend en HTML, CSS y JavaScript vanilla.

## Estructura

- `index.html` — estructura de la landing
- `css/styles.css` — estilos responsive
- `js/products.js` — catálogo de productos
- `js/main.js` — filtros, búsqueda, modal, zoom y menú
- `img/` — carpeta preparada para las fotos reales

## Cómo usarlo

Abre `index.html` en el navegador.

Las imágenes del prototipo vienen desde Unsplash para que la landing tenga contenido visual desde el principio. Para producción conviene reemplazarlas por las fotografías reales del emprendimiento.

## Para agregar productos

Edita `js/products.js` y agrega un objeto al array `productos`.

Cada producto admite:

- nombre
- categoría
- imagen
- descripción
- ingredientes
- formato
- precio
- si es a pedido

## Próximos pasos recomendados

1. Reemplazar nombre, logo y textos por los reales.
2. Incorporar fotos reales.
3. Configurar Instagram y WhatsApp.
4. Definir precios/formats.
5. Agregar alérgenos.
6. Mejorar SEO y datos estructurados.
7. Si el catálogo crece mucho, conectar los productos a un CMS.
